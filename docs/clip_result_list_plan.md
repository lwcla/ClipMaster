# 剪贴结果列表组件设计文档

## 当前状态

`ClipResultList` 是普通列表页、搜索结果页、折叠列表页和回收站列表页共同复用的剪贴结果列表组件，负责分页结果展示、空态/加载态、剪贴卡片结构、复制入口、可选右滑菜单、第二段滑动动作、关键词高亮、取消置顶后的视口修正和基础 item 测量。

本文是 `ClipResultList` 共享组件的主方案文档。后续涉及 `ClipResultList.kt`、共享卡片样式、侧滑方向、按钮布局、动画阈值、滚动修正、关键词高亮或跨页面列表结果复用的修改，都必须优先更新本文；页面文档只记录页面如何传入数据、动作语义和差异化文案。

## 目标

- 为普通列表、普通搜索、折叠列表、折叠搜索和回收站列表提供同一套剪贴结果展示体验。
- 保持剪贴记录操作清晰可点：内容点击进详情，复制常驻，置顶/删除通过右滑菜单露出。
- 支持第二段继续右滑动作，由页面传入具体语义：普通范围折叠数据，折叠范围取消折叠，回收站范围彻底删除。
- 保持分页加载、空态、append 重试和切回列表后的滚动位置稳定。
- 将卡片结构、侧滑、动画、测量和滚动修正集中在组件内维护，避免页面文档和页面实现重复分叉。

## 范围

- `ClipResultList` 共享结果列表、空态、加载态、分页 append 和 append error 重试。
- `ClipCard` 卡片展示、来源色边框、链接预览、剪贴内容、来源 App、时间、置顶角标和复制按钮。
- 可选右滑菜单、菜单按钮、第二段继续右滑提示、折叠/取消折叠/彻底删除离场动画和菜单吸附规则。
- 关键词高亮能力，供搜索页传入当前搜索词。
- 取消置顶后的视口修正，避免 `LazyColumn` 因稳定 key 自动跟随被移动 item。

不包含：

- 普通列表页的数据范围、标题、Shizuku 提示和搜索入口，详见 `docs/list_page_plan.md`。
- 搜索页的关键词输入、时间筛选、来源 App 筛选和路由范围，详见 `docs/search_page_plan.md`。
- 折叠状态的数据层、折叠入口和折叠搜索复用方案，详见 `docs/folded_clip_plan.md`。
- 回收站软删除、回收站页面、保留天数和自动清理方案，详见 `docs/recycle_bin_plan.md`。
- 首页 Pager、底部 Tab 和列表/我的页面切换策略，详见 `docs/main_page_plan.md`。

## 用户体验

- 结果使用单列竖向 item，不再使用瀑布流。
- item 保留卡片、边框和来源色；展示链接、链接标题、预览图、剪贴字符串、来源 App 和时间。
- 剪贴字符串最多展示三行，超出省略。
- item 最左侧常驻复制按钮，和左侧侧滑菜单保持同向；点击只触发复制，不进入详情；回收站列表可关闭复制按钮和普通菜单按钮，仅保留卡片展示、点击还原和继续右滑彻底删除。
- 内容区轻点进入详情，长按回调保留，由页面决定是否启用长按动作。
- item 向右拖动露出左侧置顶/取消置顶和删除按钮，向左拖动收回；列表内只允许一个 item 菜单保持展开，新 item 开始右滑时会自动收回上一个已展开菜单。
- item 在第一段右滑菜单基础上继续右滑时显示页面传入的提示文案，例如“继续右滑折叠数据”或“继续右滑取消折叠”。
- 继续右滑超过阈值并松手后，item 先完整滑出当前卡片区域，动画结束后再回调页面更新数据库，避免 Paging 刷新导致记录半途消失。
- 复制、置顶/取消置顶、删除按钮宽度统一为 48dp，图标尺寸统一为 24dp，并在各自点击区域内水平和竖向居中。
- 左侧复制按钮与内容区、置顶按钮与删除按钮之间使用 0.5dp 固定高度分割线；分割线高度为按钮图标高度加 10dp，竖向居中，颜色与卡片边框一致。
- 置顶状态角标是卡片级视觉装饰，不响应点击；它位于卡片内部最高装饰层，最后绘制并高于内容层、左侧复制按钮和选中态，避免被其他组件挡住。

## 数据和参数契约

- `pagedClips` 由页面传入，组件只消费 `LazyPagingItems<ClipShowEntity>`，不直接访问 Repository 或 ViewModel。
- `listState` 由页面持有，组件负责在取消置顶排序刷新后基于该状态恢复视口。
- 当前展开菜单 id 由 `ClipResultList` 父层维护，`ClipCard` 只上报自己开始展开或收回，避免多个 item 各自保存展开态后同时露出菜单。
- `emptyText` 由页面传入，用于区分普通列表、普通搜索、折叠列表、折叠搜索和回收站空态。
- `highlightQuery` 默认为空；搜索页传入当前关键词后，组件只在可见文本中高亮命中内容。
- `swipePastActionText` 为空时只允许普通菜单阶段；非空时开启第二段继续右滑提示和动作。
- `onSwipePastAction` 只表达第二段动作回调，具体是折叠还是取消折叠由页面决定。
- 删除、复制、置顶、详情点击、还原点击和多选点击继续通过回调传入，避免共享组件直接依赖某个页面 ViewModel。
- 时间展示由页面传入展示模式；普通范围显示原剪贴时间，回收站范围显示删除时间。

## 组件结构

- `ClipResultList`
  - 空状态：`EmptyScreen`
  - 首次 refresh loading：居中 `CircularProgressIndicator`
  - 正常数据：`LazyColumn`
  - append loading：底部小 loading
  - append error：底部可点击重试文本
- `ClipCard`
  - 外层裁剪和侧滑容器
  - 左侧侧滑操作区
  - 可横向拖动的 `ElevatedCard`
  - 卡片级最上层置顶角标装饰层
  - 自定义测量左侧复制按钮区、分割线和内容区
- 辅助 UI
  - `SourceAppNameWithTime`
  - `ClipContent`
  - `LinkPreviewContent`
  - `SwipeActionButton`
  - `HighlightableText`

## 交互规则

- 复制：点击左侧常驻复制按钮调用 `onCopy(clip)`。
- 删除：右滑后点击删除按钮调用 `onDelete(clip)`，是否弹窗确认以及移入回收站/彻底删除由页面处理。
- 置顶/取消置顶：右滑后点击置顶按钮调用 `onPinToggle(clip)`；取消置顶前组件会记录当前视口，等待 Paging 排序刷新后恢复。
- 详情：点击 item 内容区调用 `onClick(clip)`。
- 长按：长按 item 内容区调用 `onLongClick(clip)`，当前是否有可见反馈由页面决定。
- 第二段动作：右滑露出菜单后继续右滑，或在无菜单模式下直接右滑，超过阈值并松手后播放离场动画，再调用 `onSwipePastAction(clip)`。
- 多选：页面可传入选中 id 集合，组件只展示选中态并把点击/长按回调交回页面。
- 侧滑：
  - 只允许向右展开、向左收回。
  - 新 item 开始右滑时会登记为当前展开菜单，原已展开 item 监听到菜单归属变化后自动收回。
  - 关闭状态下的左滑不消费事件，交给外层首页 Pager 切到“我的”。
  - 菜单已展开或动画中时，左滑优先由 item 消费用于收回菜单，避免展开状态直接切页。
  - 普通菜单阶段最大偏移等于左侧操作区宽度。
  - 存在第二段动作时最多可拖到完整 item 宽度，触发阈值为 item 宽度 85%；无菜单的回收站 item 也沿用该阈值。
  - 松手时按操作区一半宽度吸附；未达到第二段触发阈值时使用较长吸附动画回到菜单或收起状态。
  - 侧滑偏移按 `clip.id` 使用 `rememberSaveable` 保存，父层额外保存当前展开菜单 id，避免 LazyColumn 复用导致状态串到其他记录，同时保证最多只有一个菜单可见。

## 高亮规则

- 高亮只处理用户看得见的字段，匹配词由搜索页通过 `highlightQuery` 传入。
- 当前高亮范围包含剪贴内容 `content`、链接预览标题 `linkTitle` 和来源 App 名称 `appName`。
- 关键词会先去除首尾空白，按空白拆词、去重并做大小写不敏感匹配。
- 多个词重叠时只给尚未覆盖的位置加样式，避免重复添加 Span 造成边界不可预测。
- 普通列表和折叠列表传空关键词，不额外分配高亮片段。

## 高度和测量

- 卡片内容高度由左侧内容区真实测量结果决定。
- 不再使用 `IntrinsicSize.Min + fillMaxHeight` 让按钮反向参与高度测量，避免置顶重排后小 item 继承旧首条大 item 高度。
- `ClipCard` 内部自定义 `Layout` 先扣除左侧复制按钮区和分割线宽度，再测量内容区并让复制按钮区跟随内容高度。
- 复制分割线按固定高度竖向居中，不拉满卡片高度。
- 左侧侧滑操作区通过外层 `matchParentSize()` 跟随最终 item 高度。

## 生命周期和性能约束

- 组件不主动创建分页流，不在组件内访问数据库；分页生命周期由页面通过 `flowWithLifecycle`、`collectAsLazyPagingItems` 等方式控制。
- `refresh Loading && itemCount == 0` 时展示独立 loading，不组合绑定同一个 `LazyListState` 的空 `LazyColumn`，避免空刷新窗口把滚动状态钳回顶部。
- Paging key 使用数据库主键，保证置顶、删除、搜索条件变化和侧滑状态保存时 Compose 复用稳定。
- 如果调整 item key、contentType、refresh 空态或侧滑状态保存方式，必须验证置顶、删除、搜索条件变化、切回页面、侧滑状态和滚动位置。

## 测试验证

- 编译验证：涉及组件代码改动时运行 `./gradlew :app:compileDebugKotlin`。
- item 展示验证：无链接、仅链接、仅标题、仅预览图、长剪贴字符串、置顶 item、不同来源色 item 都能正确展示。
- 点击验证：内容点击进入详情，左侧复制按钮只复制，删除和置顶/取消置顶回调正确。
- 高亮验证：剪贴内容、链接标题、来源 App 名称中命中的关键词能高亮；空关键词不高亮。
- 侧滑验证：右滑露出操作，左滑收回；先展开 A 再右滑 B 时，A 会自动收回，列表最多只有一个普通菜单可见。
- 第二段动作验证：继续右滑出现页面传入提示，超过阈值松手后 item 先完成离场动画，再由页面更新数据范围。
- 回收站验证：无复制按钮和普通菜单按钮时，继续右滑仍能触发彻底删除；卡片底部显示删除时间。
- Pager 手势验证：item 未展开时列表页左滑可以切到“我的”，item 已展开时左滑优先收回菜单。
- 高度验证：高 item 后面置顶矮 item、取消置顶矮 item，都应按自身内容包裹高度显示。
- 取消置顶滚动验证：取消置顶当前可见 item 后，列表视口停留在操作时的位置，不跟随该 item 回到原排序位置。

## 已知取舍

- 共享组件只负责展示和回调，不直接决定普通列表、搜索或折叠列表的数据范围。
- 取消置顶后恢复的是操作时的 index/offset 视口，不保证继续显示同一条内容；这是为了满足“视口不动”的体验。
- 如果取消置顶同时发生新增、删除或后台刷新，恢复视口可能有轻微偏差，但会通过 index 边界保护避免崩溃。
- 右滑菜单采用单展开模式；当前展开 id 保存在 `ClipResultList`，如果已展开 item 因分页刷新离开可见快照，父层 id 可能暂时保留，但不会展示多个菜单，下一次展开会覆盖该 id。
- 第二段动作由页面传入，普通范围折叠，折叠范围取消折叠，回收站范围彻底删除；组件不理解具体业务，只负责触发时机、无菜单模式、选中态和离场动画。

## 开放问题

- 是否需要点击列表空白处或页面切换时自动收起当前展开菜单。
- 是否需要为共享 item 增加更明确的可访问性动作，减少手势操作对辅助功能用户的依赖。
- 是否恢复长按底部弹窗，或改为更明确的更多操作入口；如果恢复，需要重新评估和侧滑、详情点击的冲突。

- 2026-05-15：补充回收站列表复用约束；原因是回收站需要复用卡片展示和右滑离场动画，但关闭复制/置顶/普通删除菜单，并显示删除时间和多选选中态。
- 2026-05-15：将常驻复制按钮从卡片右侧调整到卡片左侧；原因是侧滑菜单从左侧展开，复制入口同侧能降低视觉割裂，回收站无复制按钮场景保持不变。
- 2026-05-15：将置顶角标调整为卡片内部最高装饰层；原因是复制按钮移动到左侧后，卡片内容层和选中态可能盖住角标，需要明确角标最后绘制并高于其他兄弟节点。
- 2026-05-15：将侧滑菜单从多 item 可同时展开调整为单 item 展开；原因是列表中多个菜单同时露出会增加视觉噪音和误操作风险，新 item 开始右滑时自动收回上一个菜单。
