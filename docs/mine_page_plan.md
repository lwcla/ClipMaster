# 我的页方案

## 当前状态

我的页是首页底部 Tab 的一级页面，展示下载记录入口、折叠数据入口、回收站入口和权限说明。下载记录、折叠数据和回收站只在入口处展示轻量统计或说明，不在我的页加载对应分页数据。

本文记录我的页自身的入口、设置项和页面级交互；首页 Pager、底部 Tab 和一级标题详见 `docs/main_page_plan.md`，共享剪贴 item 的斜向快捷动作区、右滑菜单和回调规则详见 `docs/clip_result_list_plan.md`。

## 目标

- 保持我的页作为管理入口和偏好设置入口，避免在首页列表里堆叠全局设置。
- 新增“剪贴快捷操作”设置，让用户理解普通列表和普通搜索结果 item 可以通过斜向快捷动作区执行所选动作。
- 设置快捷动作时提供复制、置顶、删除、折叠、无（整卡进入详情）五个互斥选项，并在选择后立即影响普通列表和普通搜索结果。

## 用户体验

- 我的页继续使用单列卡片入口，顶部显示固定标题“我的”。
- 下载记录、折叠数据和回收站这类页面导航入口只保留卡片自身点击反馈，页面切换动画统一交给 `AppNavigation` 的 Compose Navigation 官方左进右出转场。
- “剪贴快捷操作”作为普通设置行展示当前选项摘要，例如“当前：复制”。
- 点击该设置行打开单选弹窗，选项顺序为复制、置顶、删除、折叠、无（整卡进入详情）。
- 弹窗说明普通列表和普通搜索结果 item 的快捷动作区执行所选动作，其余区域进入详情；选择“无（整卡进入详情）”会关闭快捷动作区。
- 该设置是五选一偏好，不使用开关，避免把互斥动作误表达为启用/停用。
- “剪贴快捷操作”设置行只打开本页弹窗，不参与页面级导航转场。

## 数据和接口

- 快捷动作保存到 `AppSetting.clipItemQuickAction`，默认值为复制。
- 我的页 ViewModel 只负责读取和写入设置，不直接操作剪贴列表数据。
- 普通列表页和普通搜索页观察同一设置状态并传给 `ClipResultList`；折叠列表、折叠搜索和回收站忽略该设置。
- 后续新增剪贴 item 快捷动作时，需要同步扩展设置枚举、字符串资源、单选弹窗选项、共享 item 动作映射和本文档。

## 测试验证

- 设置行展示当前选项，点击后弹出单选弹窗。
- 单选弹窗顺序为复制、置顶、删除、折叠、无（整卡进入详情）。
- 选择任一动作后弹窗关闭，设置行摘要立即更新。
- 切回普通列表和普通搜索后，快捷动作立即生效；重启应用后设置保留。
- 选择“无（整卡进入详情）”后普通列表和普通搜索不显示斜向背景，整卡点击进入详情。
- 点击下载记录、折叠数据和回收站入口时应正常进入目标页面，并由 `AppNavigation` 呈现左进右出页面切换。
- 点击“剪贴快捷操作”设置行应立即打开弹窗，不触发页面级导航转场。

## 已知取舍

- 设置只影响普通列表和普通搜索结果，不影响折叠列表、折叠搜索和回收站，避免“折叠”在不同页面产生反向语义。
- 删除动作只触发现有删除选择弹窗，不直接静默删除，避免误触造成不可恢复风险。

## 开放问题

- 后续是否需要为右半区动作也提供自定义设置暂不确定；当前右半区固定进入详情，降低学习成本。
