# 全量 UI 统一刷新方案

## 当前状态

当前应用已经有 `TitleBar`、`TopLevelTitleBar`、`ClipMasterCard`、`ListEntryCard`、`MediaStateContent`、`PagingStateContent` 和 `SharedImagePreview` 等共享组件。本轮已把主题层从默认 Material 紫色模板收敛为动态取色优先、固定品牌色板回退的主题策略，并新增主题 token 与一级/二级页面骨架；首页底部导航已移除临时红色背景，列表页和折叠页搜索入口已移到标题栏，搜索页顶部控件已从滚动折叠改为稳定搜索框 + 紧凑筛选行，详情页已按正文、提取能力和普通操作分区，删除入口上移到标题栏右侧低频危险操作位。

本方案作为本轮应用内 UI 刷新的主文档。后续涉及固定品牌主题、页面骨架、标题栏、底部导航、主要内容卡片、状态组件、列表/搜索/详情/我的主链路、流程页统一视觉或设计例外记录时，优先更新本文；页面文档只记录本页面接入方式、影响摘要和差异化行为。

## 目标

- 建立克制、专业、工具型的固定品牌视觉，避免继续沿用默认紫色模板或页面局部硬编码样式。
- 通过主题 token、页面骨架和共享组件统一全局 UI，而不是在每个页面重复调样式。
- 保留首页两 Tab、现有类型安全路由、剪贴列表/搜索/详情/我的核心业务语义和流程页状态机。
- 让按钮、空态、错误态、权限提示和流程说明更短、更明确、更可执行。
- 完成本轮主链路刷新后，将下载、备份、提取等流程页的深度骨架收敛作为明确后续任务，避免在同一轮里混入高风险业务流程改写。

## 视觉系统

- Android 12 及以上默认启用动态取色，让主题跟随系统壁纸的 tonal palette。
- Android 11 及以下继续使用应用定义的固定品牌色板作为回退，保证旧系统也有稳定的视觉基线；动态取色 API 不在低版本调用，避免 `minSdk 24` 下的可用性告警。
- 固定回退主题仍保留低对比背景、清晰 surface、主色强调和可读的错误/成功辅助色，供不支持动态取色的设备使用；当前默认回退主色已调整为接近“提交反馈”按钮的系统蓝。
- `ui/theme` 统一提供颜色、Typography、间距、圆角、描边、阴影和动效时长 token；页面和共享组件优先使用 token。
- 不引入新字体资源，第一轮使用系统字体并补齐 Material Typography 层级。
- 共享组件的主要点击区域至少保持 48dp，可点击图标按钮必须提供 `contentDescription`。

## 页面骨架和共享组件

- 新增一级页面骨架，用于首页 Tab 根页面统一顶部栏、内容背景、系统 inset 和内容间距。
- 新增二级页面骨架，用于搜索、详情、折叠、回收站、备份、恢复流程和视频下载等页面统一标题栏、内容背景和 snackbar/bottomBar 入口；下载记录、图片提取和视频提取因多选标题栏、WebView 遮罩和探测状态机暂保留页面专属 chrome。
- `TitleBar` / `TopLevelTitleBar` 统一吃主题 token，保留插槽式导航、标题和右侧动作。
- `ClipMasterCard` / `ClipMasterGestureCard` 使用统一圆角、边框、阴影和内容内边距，调用方只传业务状态色和交互回调。
- `ListEntryCard` 增加可选分组语义支持，继续承载图标、标题、说明和入口点击。
- `PagingStateContent`、`MediaStateContent` 和 `SharedImagePreview` 使用主题 token 收敛状态色、尺寸、圆角和间距。
- 删除类执行入口统一使用 `:base:general` 的 `base_general_ic_delete` 图形和 `DeleteActionIcon` / `DeleteIconButton` 组件，图标由 Compose tint 为 `MaterialTheme.colorScheme.error`；清空类入口不纳入同款删除图标统一范围，继续保留 `DeleteSweep` / `DeleteForever` 等清空语义图标并统一危险色，回收站入口卡片仍保持导航入口的 `DeleteOutline` + primary 色。

## 主链路改造

- 首页底部导航移除临时红色背景，改为更轻的图标 + 文案 + 选中指示；保留列表和我的两个 Tab，并继续使用标准 `NavigationBar` 结构，只收缩图标和标签字号来降低占用感。
- 首页底部导航背景需要贴住系统导航区，不能因为 inset 叠加表现为悬浮条或与正文之间留出明显缝隙。
- 首页列表结果区只保留一层 12dp 的页面私有底部留白，让最后一条记录和底部导航之间有明确但不过分的呼吸感，不再出现明显空白带。
- 所有复用 `ClipResultList` 的普通态页面统一使用 12dp 底部留白；只有回收站多选态这类存在底部操作栏的页面，才继续单独预留更大底部空间。
- 下载记录的视频列表和图片列表虽然不复用 `ClipResultList`，但普通态底部留白也对齐到同一档 12dp 视觉节奏；页面根布局已改为标准 `Scaffold`，多选态底部删除条和系统导航区统一通过 `bottomBar`/`paddingValues` 参与内容布局，避免最后几项被遮挡。
- 一级页面骨架默认不再消费底部系统导航区 inset，避免列表页和我的页正文被整体抬离底部导航。
- 列表页搜索入口从右下角 FAB 移到一级标题栏右侧动作，减少悬浮控件对最后一屏内容的遮挡。
- 折叠数据页继续保留搜索能力，并和列表页一样收敛到标题栏动作，避免右下角悬浮按钮遮挡最后一屏内容。
- 搜索页改为稳定的返回栏、搜索框、紧凑筛选行和结果区结构，不再使用滚动折叠顶部控件；保留搜索历史、来源筛选和查询逻辑。
- 搜索页单独验收键盘弹出、焦点切换、提交搜索、返回键关闭历史面板、筛选区高度和结果列表剩余空间。
- 详情页改为分区式布局：正文内容、链接提取能力、普通操作；复制保留为主操作，删除上移到标题栏右侧低频危险操作位。
- 我的页入口按“权限”“数据管理”“功能入口”“设置”分组，权限分组置顶；页面仍只负责权限动作、系统跳转和设置保存。

## 设计例外和后续收敛

- 回收站、折叠列表页、备份页、备份恢复流程页和视频下载页已接入统一二级页面骨架；下载记录、图片提取和视频提取本轮先接入共享主题 token、标题栏、卡片和状态组件，不强行改写内部状态机和复杂布局。
- 下载记录暂未切入 `SecondaryPageScaffold`，原因是普通态和多选态标题栏需要在同一页面内切换并与选择操作条协同；但页面根布局已切到标准 `Scaffold`，后续只需在二级骨架支持可变标题栏插槽后再迁入该页面。
- 图片提取和视频提取暂未切入 `SecondaryPageScaffold`，原因是透明/隐藏 WebView、前景状态遮罩、探测超时和重试状态紧密绑定页面 chrome；后续应先抽出可复用的“WebView 探测页骨架”，再迁入两类提取页。
- 任意页面如果保留硬编码尺寸、特殊布局或页面私有组件，必须说明业务原因和后续收敛方向。
- 视觉完成线：所有页面完成统一骨架、主题 token、深浅色、动态字体、空态/错误态和关键交互验收后，才算本轮 UI 优化完成；只换颜色但未完成骨架统一的页面不能标记完成。

## 日志与诊断计划

- 本轮 UI 刷新以 Compose 视觉、页面骨架和入口布局调整为主，不新增网络、文件、数据库、后台任务、备份恢复或权限副作用。
- 纯样式、标题栏、卡片、间距、颜色和页面分组调整不新增运行时日志，避免制造高频噪声。
- 删除按钮统一只调整共享图形来源、按钮热区和危险色表达，不新增删除、清空、数据库、文件或错误分支副作用，因此不新增运行时日志。
- 如果后续实现中改变页面生命周期、搜索输入状态机、导航层级、长任务入口或错误分支，需要在对应页面文档补充日志点、字段、脱敏策略和验证方式。
- 截图审计、人工验收和编译验证作为本轮主要诊断方式，不记录剪贴内容、搜索词全文、完整 URL、WebDAV 地址或本地授权 URI。

## 测试验证

- 文档验证：新增或更新本文，并同步列表页、搜索页、详情页、我的页、首页、共享卡片和共享表单组件文档。
- 编译验证：运行 `./gradlew :app:compileDebugKotlin`。
- 磁力模块验证：运行 `./gradlew :app:compileDebugKotlin -PenableMagnetFeature=true`，确认可选模块入口样式和宿主边界仍稳定。
- 单元测试策略：纯 UI 样式、文案、薄导航接线不新增 JVM 单元测试；如果抽出新的纯 Kotlin formatter、mapper、状态判断或派生规则，需要补测试。
- 人工验收：浅色/深色、默认字体/放大字体、空态/加载/错误/有数据、列表切回位置、重复点击列表 Tab 回顶、搜索历史和筛选语义、详情复制/删除/提取路径。
- 反回归筛查：使用 `rg "Color\\.|\\.dp|RoundedCornerShape|shadow"` 等方式人工检查硬编码样式，合理例外记录到本文或对应页面文档。

## 变更记录

- 2026-06-08：统一全 App 删除类入口为列表菜单同款删除图标，并明确清空类入口只统一危险色、不替换成单条删除图标；原因是删除动作需要一致识别，清空动作仍需保留批量清理语义。
- 2026-06-05：我的页权限分组独立并置顶，“设置与权限”改为“设置”；原因是权限状态需要成为我的页第一组信息，设置分组只保留普通偏好。
- 2026-05-31：将详情页删除入口从正文底部危险操作区移动到标题栏右侧；原因是删除属于低频危险操作，应减少对详情页底部高频操作区的干扰。
- 2026-05-28：将固定回退主题主色调整为按钮蓝；原因是用户在暂时关闭动态取色后，希望先验证一套明确的蓝色默认主题，而不是此前偏暖的红棕色。
- 2026-05-28：将首页底部导航调整为标准 `NavigationBar` 的轻量化样式；原因是用户希望尽量保持标准组件结构，仅通过更小的图标和标签字号减轻底栏观感占用，而不是引入页面私有导航实现。
- 2026-05-28：补充动态取色的系统版本门槛，并将兼容主题入口默认值改为开启；原因是 `dynamicDarkColorScheme` / `dynamicLightColorScheme` 只能在 Android 12+ 调用，同时旧入口默认关闭会让实际应用仍然回退固定主题。
- 2026-05-28：主题入口改为动态取色优先；原因是用户希望默认主题直接跟随系统动态配色，同时保留固定色板作为旧系统回退。
- 2026-05-28：将下载记录页根布局切到标准 `Scaffold`；原因是三键导航下内容区和底部删除条需要统一走 `paddingValues` 路径，不能继续依赖页面手动补系统导航高度。
- 2026-05-28：为下载记录视频/图片列表的多选态补充底部让位空间；原因是下载记录页暂未切入统一 `bottomBar` 骨架，底部删除条采用 overlay 方式显示，需要由列表自身在多选态主动预留空间。
- 2026-05-28：将折叠列表页根布局切到 `SecondaryPageScaffold`；原因是它此前仍走手写 `Column + TitleBar` 路径，不利于和其他二级页对齐 inset/padding 行为，也会干扰底部间距排查。
- 2026-05-28：按确认结果将统一列表底部节奏固定回 12dp；原因是 8dp 在下载记录、折叠列表等页面的卡片体量下偏紧，12dp 更适合作为本轮普通列表的统一轻量留白。
- 2026-05-28：继续收细通用列表底部留白，并把下载记录视频/图片列表一并对齐；原因是部分页面在统一到 12dp 后最后一个 item 仍显得偏高，需要把普通列表、折叠列表、搜索结果、回收站普通态和下载记录列表一起收口到更克制的底部节奏。
- 2026-05-28：统一普通剪贴结果列表的底部留白规则；原因是首页列表、折叠列表、搜索结果和回收站普通态都复用 `ClipResultList`，底部节奏需要一起收口，避免同类页面观感分叉。
- 2026-05-28：将首页列表底部间距收敛为轻量留白；原因是完全贴合底部导航会让最后一个 item 观感过硬，本轮改为保留更克制的底部呼吸感。
- 2026-05-28：关闭一级页面骨架的默认底部 inset；原因是问题不只出现在列表滚动区，我的页也会整体上移，说明根因在 `TopLevelPageScaffold` 的默认系统安全区消费。
- 2026-05-28：移除首页列表与底部导航之间的额外滚动留白；原因是导航栏贴底后，列表页额外 24dp `contentPadding.bottom` 会继续制造视觉间距。
- 2026-05-28：修正首页底部导航的系统导航区 inset 处理；原因是此前底栏外层和内容层同时消费底部安全区，导致底栏上浮且与内容之间出现明显间距。
- 2026-05-27：新增全量 UI 统一刷新主方案；原因是应用内视觉系统需要从默认模板收敛为固定品牌主题，并通过共享页面骨架和 token 统一主链路体验。
- 2026-05-27：同步记录本轮 UI 刷新实现范围；原因是主题 token、一级/二级页面骨架、列表/搜索/详情/我的主链路、回收站、备份恢复和视频下载已落地，下载记录与提取页因页面专属状态机暂保留后续收敛例外。
