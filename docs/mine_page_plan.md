# 我的页方案

## 当前状态

我的页是首页底部 Tab 的一级页面，依次展示权限项、备份与恢复、下载记录、折叠数据、回收站和检查更新入口；当 `:feature:magnet` 通过 `-PenableMagnetFeature=true` 编译进应用时，页面通过 `MagnetFeatureEntry.MineEntry` 追加磁力搜索入口，完整磁力模块化规则以 `docs/magnet_search_plan.md` 为准。磁力搜索、下载记录、折叠数据和回收站只在入口处展示轻量说明或统计，不在我的页同步源索引、执行搜索或加载对应分页数据。检查更新入口只负责触发轻量版本检查、展示结果和打开外部发布链接，完整自更新规则以 `docs/app_update_plan.md` 为准。本轮 UI 刷新后，我的页通过 `TopLevelPageScaffold` 接入统一一级页骨架，并按“权限”“数据管理”“功能入口”“设置”分组展示入口。

本文记录我的页自身的入口、设置项和页面级交互；首页 Pager、底部 Tab 和一级标题详见 `docs/main_page_plan.md`，共享剪贴 item 的斜向快捷动作区、右滑菜单和回调规则详见 `docs/clip_result_list_plan.md`。

当前代码组织已将我的页入口卡片、剪贴快捷动作设置弹窗和权限设置项适配层拆到同 package 组件文件中；`MinePage.kt` 保留页面状态收集、权限动作消费、生命周期刷新和系统跳转，避免页面入口继续混合所有 UI 细节。入口卡片、入口式开关卡片、单选弹窗、固定设置开关列表和设置开关行的完整共享规则以 `docs/shared_form_components_plan.md` 为准，本文只记录我的页接入方式和快捷动作业务差异。

## 目标

- 保持我的页作为管理入口和偏好设置入口，避免在首页列表里堆叠全局设置。
- 新增“剪贴快捷操作”设置，让用户理解普通列表和普通搜索结果 item 可以通过斜向快捷动作区执行所选动作。
- 设置快捷动作时提供复制、置顶、删除、折叠、无（整卡进入详情）五个互斥选项，并在选择后立即影响普通列表和普通搜索结果。

## 用户体验

- 我的页继续使用单列卡片入口，顶部显示固定标题“我的”，入口按权限、数据管理、功能入口、设置分组。
- 权限分组固定放在我的页最上面，只展示 Shizuku 和通知两个权限项；两个权限项各自独立成卡，方便用户先看到影响剪贴读取和提醒展示的系统能力状态。
- 备份与恢复、下载记录、折叠数据、回收站以及可选磁力搜索这类页面导航入口只保留卡片自身点击反馈，页面切换动画统一交给 `AppNavigation` 的 Compose Navigation 官方左进右出转场。
- 磁力搜索入口只在磁力模块启用时出现，并且只负责进入磁力搜索页；Academic Torrents 索引状态、同步动作、搜索历史和结果分页都在磁力搜索页按生命周期启动。
- 检查更新入口展示当前 App 版本，点击后执行手动版本检查；Gitee 与 GitHub 更新源均不可达时展示“暂时无法检查更新，可稍后重试或前往发布页查看”，并提供可配置发布页入口。
- “剪贴快捷操作”作为普通设置行展示当前选项摘要，例如“当前：复制”。
- 点击该设置行打开单选弹窗，选项顺序为复制、置顶、删除、折叠、无（整卡进入详情）。
- 弹窗说明普通列表和普通搜索结果 item 的快捷动作区执行所选动作，其余区域进入详情；选择“无（整卡进入详情）”会关闭快捷动作区。
- 该设置是五选一偏好，不使用开关，避免把互斥动作误表达为启用/停用。
- “剪贴快捷操作”设置行只打开本页弹窗，不参与页面级导航转场。
- “权限”分组不再提供“权限说明”标题行、收起/展开按钮或展开动画。
- Shizuku 和通知权限不放在同一个卡片里，每个权限项都单独使用一张卡片，和其他分组入口保持一致的扫描节奏。
- 权限单项卡片内部展示权限语义图标、短标题、完整说明文案和右侧开关；短标题用于和其他入口卡片保持一致的扫描节奏，说明文案继续承载权限影响边界。
- Shizuku 和通知权限项的说明文案必须完整换行显示，不使用两行省略，避免用户看不到通知关闭后“剪贴仍会保存”等关键说明。
- 通知权限项只表达剪贴保存、下载进度、下载结果和 Shizuku 状态提醒的展示能力；关闭通知不影响剪贴入库。

## 数据和接口

- 快捷动作保存到 `AppSetting.clipItemQuickAction`，默认值为复制。
- 我的页 ViewModel 只负责读取和写入设置，不直接操作剪贴列表数据。
- 普通列表页和普通搜索页观察同一设置状态并传给 `ClipResultList`；折叠列表、折叠搜索和回收站忽略该设置。
- 后续新增剪贴 item 快捷动作时，需要同步扩展设置枚举、字符串资源、单选弹窗选项、共享 item 动作映射和本文档。
- 检查更新使用 app 模块内的自更新协作者；我的页只持有入口 UI state、触发检查和分发外部链接打开事件，不承载 manifest 解析、版本比较或下载源排序逻辑。
- Shizuku 和通知权限项只使用页面内瞬时状态，不保存“权限说明是否展开”的 MMKV 偏好；历史 `permission_expanded` key 已废弃且不进入备份恢复协议。

## 测试验证

- 切换到我的页后，最上方应先显示“权限”分组，分组下只有 Shizuku 和通知两个权限项，且两个权限项应分别展示为独立卡片。
- 权限单项卡片内部应展示权限语义图标、Shizuku/通知短标题、完整说明文案和对应开关。
- Shizuku 和通知两个权限项的说明文案应完整显示；放大字体下也不能出现省略号截断关键权限说明。
- 设置行展示当前选项，点击后弹出单选弹窗。
- 单选弹窗顺序为复制、置顶、删除、折叠、无（整卡进入详情）。
- 选择任一动作后弹窗关闭，设置行摘要立即更新。
- 切回普通列表和普通搜索后，快捷动作立即生效；重启应用后设置保留。
- 选择“无（整卡进入详情）”后普通列表和普通搜索不显示斜向背景，整卡点击进入详情。
- 点击下载记录、折叠数据和回收站入口时应正常进入目标页面，并由 `AppNavigation` 呈现左进右出页面切换。
- 启用磁力模块时，点击磁力搜索入口应进入磁力搜索页；默认禁用构建不展示该入口。我的页不应提前下载源索引或读取磁力记录分页。
- 点击“剪贴快捷操作”设置行应立即打开弹窗，不触发页面级导航转场。
- 点击“检查更新”入口时应触发手动检查；无更新、有更新、Gitee 优先、GitHub 兜底和发布页入口均按 `docs/app_update_plan.md` 验证。
- “设置”分组下只展示剪贴快捷操作，不再混入 Shizuku 或通知权限项。

## 已知取舍

- 设置只影响普通列表和普通搜索结果，不影响折叠列表、折叠搜索和回收站，避免“折叠”在不同页面产生反向语义。
- 删除动作只触发现有删除选择弹窗，不直接静默删除，避免误触造成不可恢复风险。

## 开放问题

- 后续是否需要为右半区动作也提供自定义设置暂不确定；当前右半区固定进入详情，降低学习成本。

## 本次同步

- 我的页入口卡片和权限设置项列表已接入 `ClipMasterCard` 公共内容卡片外壳；外边距和页面入口语义仍由本页面维护，公共外壳只负责圆角、阴影、边框和触摸裁剪规则，完整规则详见 `docs/shared_card_component_plan.md`。磁力入口卡片由 `:feature:magnet` 自己渲染，宿主只提供打开动作。
- 我的页入口项复用 `ListEntryCard`；快捷动作设置弹窗复用 `SingleChoiceDialog`；权限项复用 `SettingSwitchEntryCard`，分别渲染 Shizuku 与通知两张入口式开关卡片。`SettingSwitchListCard` 继续作为表单式多项设置列表保留在共享组件中。本页面保留权限动作消费、系统跳转、Shizuku 回调监听和快捷动作枚举到资源文案的映射。
- 自更新能力以 `docs/app_update_plan.md` 作为主文档；我的页只记录入口展示、用户触发和页面可见时的轻量检查边界，避免重复维护 GitHub/Gitee 发布契约。
