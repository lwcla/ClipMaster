- `MineVm` 增加轻量本地/WebDAV 结果 Flow，保持最新代码中快捷动作/来源过滤独立字段订阅；`MinePage` 使用生命周期感知收集，`BackupEntry` 只做结果展示适配与导航，不依赖备份执行或凭据。
- 移除本页普通设置提交后的 `scheduleAfterCommittedChange`，以及仅服务此调用的 import/错误提示；业务设置提交和保存失败反馈保留。来源过滤页的调度移除纳入备份主方案清单，不在本页重新描述规则。
- 页面展示不新增运行时成功日志；结果读取失败沿用低敏 WARN 和显式重读，不由重组重复输出，也不触发备份。
