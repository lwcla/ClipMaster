# 首页主 Tab 页面体验方案

## 当前状态

首页由底部 Tab 和横向 Pager 承载“列表”和“我的”两个一级页面。当前“列表”和“我的”页已移除 `CollapsingTitle` 大标题与滚动收起效果，改为固定且居中的一级页面小标题栏；标题栏不显示返回按钮，只用于表达当前页面身份，并统一保留状态栏安全区。

当前底部 Tab 仍按原逻辑处理重复点击：已经停留在“列表”页时再次点击列表入口会回到顶部；从“我的”切回“列表”只切换页面并保留列表原滚动位置。

当前列表 item 的菜单、折叠和取消折叠已统一改为右滑，首页横向 Pager 恢复在“列表”页左滑切到“我的”；“我的”页仍保留右滑回“列表”的能力。item 已展开时，左滑优先收回菜单，菜单关闭后再交给 Pager。

## 目标

- 去掉列表页和我的页的大标题展示与折叠收起动画。
- 保留一级页面居中标题，但不显示返回按钮，避免底部 Tab 根页面出现错误返回语义。
- 保留系统状态栏安全区，避免内容贴到状态栏下方。
- 列表页保留横向 Pager 左滑切到“我的”；我的页保留右滑回列表。
- 保持列表页分页、搜索入口、删除弹窗、权限提示和我的页下载记录入口、折叠数据入口、权限开关行为不变。

## 范围

- 调整 `ClipListPage` 根布局，不再通过 `CollapsingTitle` 包裹内容。
- 调整 `MinePage` 根布局，不再通过 `CollapsingTitle` 包裹内容。
- 新增 `TopLevelTitleBar` 作为一级页面标题栏，复用通用标题栏的状态栏 padding、48dp 内容高度、覆盖式居中标题布局和统一标题文案样式，但不提供返回按钮。
- 不删除 `CollapsingTitle` 组件，后续如果特殊页面确实需要大标题折叠效果仍可复用。
- 不调整底部导航、Pager 切换、列表分页和设置项业务逻辑。

## 用户体验

- 打开 App 首页后，列表页顶部居中显示固定小标题“列表”，下方展示权限提示和剪贴内容列表，不再显示大号折叠标题。
- 切换到我的页后，页面顶部居中显示固定小标题“我的”，下方展示下载记录入口和权限设置卡片，不再显示大号折叠标题。
- 页面滚动时不再触发标题收起动画，减少首屏空间占用和滚动过程中的视觉干扰。
- 从“我的”Tab 切回“列表”Tab 时保留列表原滚动位置；只有当前已经停留在“列表”Tab 后再次点击列表入口，才执行回到顶部。
- 在列表页从关闭状态左滑时切到“我的”；item 右滑展开后，左滑优先收回 item 菜单，收回后继续左滑才切到“我的”。

## 数据流

- 当前首页主 Tab 仍只负责承载列表页和我的页；折叠数据入口在我的页内部导航到二级折叠列表页，不改变底部 Tab 结构。
- 列表页仍在 `STARTED` 生命周期内收集分页数据。
- 我的页仍由 `MineVm` 提供权限状态并通过页面层执行系统授权或设置跳转。
- 我的页折叠数据数量由 `MineVm` 订阅轻量 COUNT Flow 展示，不加载折叠列表来统计。
- 竖向列表切回时保留位置依赖主页面持有的 `LazyListState`；共享结果列表在 Paging refresh 且 `itemCount == 0` 的瞬间展示独立 loading，不组合绑定该 state 的空 `LazyColumn`，避免空刷新窗口把列表状态钳回顶部，组件细节以 `docs/clip_result_list_plan.md` 为准。

## 测试验证

- 编译验证：运行 `./gradlew :app:compileDebugKotlin`。
- 列表页验证：进入首页列表 Tab，居中显示无返回按钮的小标题“列表”，不显示大号折叠标题，搜索按钮、分页列表、删除弹窗行为保持不变。
- 我的页验证：切换到我的 Tab，居中显示无返回按钮的小标题“我的”，不显示大号折叠标题，下载记录入口和权限开关行为保持不变。
- 折叠入口验证：我的页展示折叠数据入口和折叠数量，点击后进入二级折叠数据页，底部 Tab 结构不变化。
- 滚动验证：两个页面滚动时不再出现标题折叠或收起动画。
- Tab 切换验证：列表滚动到中段后切到“我的”再切回“列表”，列表保持原位置；停留在“列表”时再次点击列表 Tab，列表回到顶部。
- Pager 手势验证：列表页关闭状态左滑可以切到“我的”；我的页右滑可以回到列表页；item 展开后左滑优先收回菜单。

## 已知取舍

- 一级页面标题使用覆盖式居中布局，不通过补一个虚拟返回按钮来制造居中效果；这样既保留根页面没有返回语义的结构，也能让标题视觉上稳定居中。
- `CollapsingTitle` 暂时保留为未使用通用组件，避免未来需要大标题折叠页面时重新实现；如果长期没有使用方，可在后续清理中删除。

## 开放问题

- 后续是否需要在列表页一级标题右侧放置搜索入口暂不确定；当前仍保留右下角 FloatingActionButton。
- 折叠数据入口目前放在下载记录入口下方；后续如果“我的”页入口增多，可再考虑分组。
